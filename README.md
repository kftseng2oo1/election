# 選舉民調得票試算器

把任何縣市、任何選舉的民調數字換算成票數的單頁 PWA。

**線上使用：** https://kftseng2oo1.github.io/election/

## 功能

- 自訂選舉名稱、合格選舉人數、樣本數
- 候選人可增減（至少 2 人），每人填支持度、一定會投／可能會投比例、代表色
- 「未明確回答」者流向：平分給前兩名、所有人平分、依支持度比例、依民調傾向指標
- 「不投票／投廢票」不分配給候選人；啟用投票意願加權時，這群人如果出門投票，選票算成廢票
- 投票意願加權：「只計一定會投 × 投票機率」或「三類加權」，可推算投票率
- 結果：各候選人得票、圓形圖圖卡（可下載、分享到 LINE）、前兩名票差、追平門檻、民調差距誤差（95%）、投票率敏感度表
- 設定自動存在瀏覽器（localStorage），可用「設定碼」複製到其他裝置
- 範例：2026 台北市長選舉（信民兩岸研究協會 10 月、11 月民調）
- 可加入主畫面，離線使用

## 計算方式

1. 族群投票機率 = 一定會投 % × 機率① ＋ 可能會投 % × 機率② ＋ 其他 % × 機率③（「擇一」模式下 ② ③ 為 0）
2. 候選人加權票 = 支持度 × 投票機率 ＋ 未明確回答 × 投票機率 × 流向比例
3. 有效票 = 選舉人數 × 投票率 ×（1 − 廢票率），再依加權票占比分配

試算結果只是把民調數字換算成票數，不代表選舉預測。
